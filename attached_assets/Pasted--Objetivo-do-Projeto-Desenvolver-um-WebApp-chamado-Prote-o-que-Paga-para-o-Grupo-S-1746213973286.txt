## 🎯 Objetivo do Projeto Desenvolver um **WebApp** chamado **"Proteção que Paga"** para o **Grupo Santana**, permitindo que qualquer pessoa maior de 18 anos possa se cadastrar como **indicador** e ganhar dinheiro trazendo amigos, conhecidos ou pessoas abordadas que possuam veículos **sem seguro**. --- ## 👥 Tipos de Usuários - **Indicador**: Usuário que se cadastra para indicar outras pessoas e ganhar dinheiro. - **Administrador**: Funcionário do Grupo Santana que gerencia e valida os prazos e libera pagamentos. --- ## 🧩 Funcionalidades ### 1. Cadastro e Login - Cadastro do Indicador: - Nome completo - CPF - Data de nascimento - E-mail - Chave PIX (opção de CPF, e-mail ou telefone) - **Login** apenas via **e-mail e senha**. - Não será utilizada **confirmação de e-mail**: após cadastrar-se, o usuário já poderá começar a indicar. --- ### 2. Área do Indicador (Dashboard) - Visualização de: - Total de saques realizados - Valor provisionado - Valor liberado para saque - Histórico de saques (válidas, inválidas com motivo, em análise) - Histórico de saques - Funções: - Cadastrar novos agendamentos (máximo de **30 por dia**) - Solicitar saque (mínimo R$50,00) - Editar informações pessoais e chave PIX - Se atingir 30 agendamentos, o **botão de nova indicação será bloqueado** até o dia seguinte, exibindo um **aviso** ao tentar clicar. --- ### 3. Realizar Indicações - Para cada Indicado: - Nome completo - Placa do carro (formatos aceitos: padrão Mercosul `ABC1D23` e modelo antigo `ABC-1234`) - Número de celular - E-mail - Pergunta: "Tem seguro?" (Sim ou Não) - **Validação automática na hora da indicação**: - **Não permitir**: - Mesmo número de celular - Mesma placa de carro - Se já existir, deve bloquear a indicação. --- ### 4. Validação de Indicações - O **Administrador** validará as restrições: - Aprovar como "válida" (contato verdadeiro e utilizável) - Marcar como "inválida" (com motivo visível para o indicador) - Cada indicação válida gera: - R$3,00 por contato validado - R$10,00 a cada 3 contatos validados - R$50,00 extras se o indicado fechar contrato de seguro ou proteção --- ### 5. Sistema de Saques - Regras: - Valor mínimo para saque: **R$50,00** - Saques serão **registrados** no app para o Admin realizar **manual via PIX**. - Sem desconto ou taxa de saque. - Tabela de pedidos de saque: - Indicador - Valor solicitado - Dados da solicitação - Status (Pendente / Pago) --- ### 6. Administração - Dashboard administrativo: - Visualizar e validar periódicos - Visualizar pedidos de saque - Controlar histórico de saques - Bloquear usuários que tentam fraudar o sistema - O sistema irá **bloquear automaticamente** um indicador que tentar enviar **múltiplos cadastros falsos** ou **duplicados**. --- ## 🛠️ Banco de Dados Supabase (Estrutura) - **Tabela:indicadores** - id (UUID) - nome_completo - cpf - data_nascimento - email - chave_pix - tipo_chave_pix - saldo_provisionado - saldo_liberado - total_indicacoes - total_saques - status (ativo/bloqueado) - data_cadastro - **Tabela: indicacoes** - id (UUID) - id_indicador (UUID) - nome_indicado - placa_carro - celular - email - possui_seguro (boolean) - status_indicacao (em análise, válido, inválido) - motivo_invalido (texto) - valor (R$3,00) - bônus (R$10,00 a cada 3 restrições) - fechamento (R$50,00 se fechar seguro) - data_indicacao - **Tabela: saques** - id (UUID) - id_indicador (UUID) - valor - data_solicitacao - status (pendente, pago) --- ## 🔐 Segurança - Todas as rotas exigem autenticação JWT. - Proteção contra duplicidade de frequência. - Dados pessoais criptografados. - Conformidade com a **LGPD**. --- ## 📜 Termos de Uso e Política de Privacidade **Termos de Uso**: - Aceite obrigatório no momento do cadastro. - Indicador concorda que: - Os dados indicados serão usados ​​para oferta de seguro/proteção. - Não poderá cadastrar dados falsos. - Saques dependentes de validação e disponibilidade de saldo. **Política de Privacidade**: - Os dados coletados (tanto do indicador quanto dos indicados) serão usados ​​exclusivamente para fins de contato comercial. - Nenhum dado será vendido ou compartilhado com terceiros. - Todos os dados serão armazenados de forma segura em conformidade com a LGPD. O aceite será registrado por **captura de opt-in** (check-box marcado no momento do cadastro, salvando na tabela o campo `aceite_termos = true`). --- ## 📈 Fluxo de Trabalho 1. Indicador faz cadastro → Já pode acessar o painel 2. Indicador de realização periódica 3. Validação automática no momento da indicação (não permite placa ou celular duplicado) 4. Admin valida manualmente as restrições 5. Saldo vai sendo provisionado → Liberado após validação 6. Indicador solicitação saque quando tiver mais de R$50 7. Admin visualizar e realizar pagamento manual do saque --- ## 📲 Requisitos no Bolt.NEW - Frontend clean e responsivo (principalmente para celular). - Backend conectado ao Supabase (autenticação, dados e funções). - Fluxo de aprovação simples e objetivo. - Atualização de saldo **em tempo real** no painel do indicador. - Mensagens de feedback claras e amigáveis ​​ao usuário.saques** - id (UUID) - id_indicador (UUID) - valor - data_solicitacao - status (pendente, pago) --- ## 🔐 Segurança - Todas as rotas devem exigir autenticação JWT. - Proteção contra duplicidade de frequência. - Dados pessoais criptografados. - Conformidade com a **LGPD**. --- ## 📜 Termos de Uso e Política de Privacidade **Termos de Uso**: - Aceite obrigatório no momento do cadastro. - Indicador concorda que: - Os dados indicados serão usados ​​para oferta de seguro/proteção. - Não poderá cadastrar dados falsos. - Saques dependentes de validação e disponibilidade de saldo. **Política de Privacidade**: - Os dados coletados (tanto do indicador quanto dos indicados) serão usados ​​exclusivamente para fins de contato comercial. - Nenhum dado será vendido ou compartilhado com terceiros. - Todos os dados serão armazenados de forma segura em conformidade com a LGPD.
